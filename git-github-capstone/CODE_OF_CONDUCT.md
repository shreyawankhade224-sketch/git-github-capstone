# Code of Conduct

## Our Pledge
We want everyone who takes part in this project to have a friendly, safe and welcoming experience, regardless of age, background, gender, ability, or experience level.

## Expected Behaviour
- Be respectful and kind to other contributors.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.

## Unacceptable Behaviour
- Harassment, insults, or discriminatory language.
- Personal attacks or trolling.
- Publishing others' private information without permission.

## Enforcement
Project maintainers may remove comments, commits, or contributions that do not follow this Code of Conduct, and may block contributors who repeatedly break it.
