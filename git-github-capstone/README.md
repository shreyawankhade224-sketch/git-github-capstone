# git-github-capstone

This repository is my final project for the Introduction to Git and GitHub course.
It contains the standard open-source project files (license, code of conduct,
contributing guide) and a small shell script that calculates simple interest.

## Files
- `LICENSE` - Apache License 2.0
- `CODE_OF_CONDUCT.md` - expected behaviour for contributors
- `CONTRIBUTING.md` - how to contribute
- `simple-interest.sh` - shell script to calculate simple interest

## Usage
```
bash simple-interest.sh
```
